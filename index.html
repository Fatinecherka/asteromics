Services

Support at every stage of a project

Projects can start at any of the three stages below, including after the data has been generated.

Design

  • Experimental and study design
  • Feasibility and sample size assessment
  • Platform and technology selection
  • Analysis plans for grant applications

Analysis

  • Quality control and preprocessing
  • Cell type annotation and clustering
  • Differential expression and abundance
  • Pathway and enrichment analysis
  • Integration across omics layers
  • Re-analysis of public datasets

Publication

  • Figures prepared to journal specifications
  • Methods and statistics sections
  • Review of analytical claims before submission
  • Responses to reviewer comments
  • Revision and resubmission support

Deliverables

What is provided at the end of a project

ReportWritten analysis report covering methods, results and analytical decisions.
FiguresVector files at journal resolution, with the underlying source data.
Methods textMethods and statistics sections written for direct inclusion in a manuscript.
CodeVersion-controlled repository, documented, with pinned package versions and fixed random seeds.
HandoverA walkthrough session so that your team can rerun the analysis independently.

Reproducibility

Analyses that can be rerun and verified

Every analysis is delivered as code rather than as results alone. Package versions are pinned, environments are documented and random seeds are fixed, so that figures can be regenerated by your team, by a collaborator or by a reviewer.

Engagement

How a project is set up

01

First consultation

A first discussion to define the biological question, the data available or planned, and the objective. Free of charge, with the time it takes.

02

Written proposal

Scope, deliverables, timeline and price, agreed in writing before work begins. Fixed price for defined projects, hourly rate for advisory work.

03

Delivery

Report, figures, methods text and code repository, followed by a handover session with your team.
